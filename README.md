# Jean-Jacques' Skyhawk School — Flight Simulator

Browser-based Cessna 172N (N4975F, 1979, 180 hp) flight simulator at KMYF Montgomery-Gibbs, San Diego.

## Run it

Open `index.html` in a browser, or serve it (e.g. `python3 -m http.server`) and open http://localhost:8000/

No build step, no install. Single self-contained HTML file.

## What is in it

- Procedural San Diego terrain: coastline, Mission Bay, Mt. Soledad, Cowles Mountain, Miramar, Gillespie, Lindbergh / downtown
- Full instrument panel: airspeed, Garmin G5, altimeter, DG, VSI, turn coordinator, GNS 430W, COM 119.20 / NAV 117.80, engine gauges, moving map with GPS Direct-To
- Throttle / mixture / carb heat / flaps (UP–40°), trim, stalls, ground effect, wind, carb ice
- Lessons, checklists, V-speeds, engine and avionics tabs, Jean-Jacques' log
- Graded checkrides: 7-maneuver mock checkride and ACS Area IV takeoff & landing ride
- Keyboard / mouse / on-screen yoke controls, sound, pause

Built with Muse.
